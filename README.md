# Ferrovia-SA-DS

Linfer

Objetivo do projeto
O sistema tem como objetivo gerenciar e monitorar operações ferroviárias, permitindo o controle de trens, sensores, rotas, relatórios e manutenções em uma plataforma web centralizada.  
Busca otimizar a gestão operacional, melhorar a segurança e facilitar a tomada de decisões em tempo real.

Contexto
O projeto foi idealizado como uma solução digital para sistemas ferroviários, simulando o funcionamento de uma central de controle.  
A aplicação oferece funcionalidades administrativas que possibilitam o acompanhamento de trens e sensores, o registro de ocorrências e o controle de manutenção preventiva.

Funcionalidades principais
- Cadastro e login de usuários (autenticação)
- Painel de controle com informações gerais
- Gerenciamento de trens (cadastro, listagem e exclusão)
- Monitoramento de sensores instalados na ferrovia
- Registro e acompanhamento de manutenções
- Emissão e listagem de relatórios operacionais
- Sistema de notificações automáticas
- Edição de perfil de usuário

Tecnologias utilizadas
- Linguagem: PHP  
- Front-end: HTML, CSS, JavaScript  
- Banco de dados: MySQL  
- Servidor local: XAMPP / Apache  
- Arquitetura: Estrutura modular baseada em páginas PHP
